# 杏野创作台 · API 版

本版本通过外接生图 API 生成图片，保留人物参考、姿势选择、服装选择、参考 2 用途、最终提示词预览和生成结果保存功能。浏览图库和生成图片统一使用 **启动创作台.cmd**。随包提供 Windows x64 的 Node.js 运行环境和完整参考图库，解压后即可打开创作台，无需安装 ComfyUI、Python 或下载本地模型。

## 开始使用

1. 将整个压缩包解压到可写目录，例如 `D:\PoseAtlas-API`，不要直接从压缩包内运行。
2. 双击 **启动创作台.cmd**，浏览器会打开本机创作台。若默认端口被占用，启动程序会选择空闲端口。
3. 打开页面中的 **生图 API 设置**，填写服务商提供的接口地址、API Key 和模型名称，并选择对应协议。
4. 保存设置后，选择姿势或服装，按需上传一至两张人物／场景参考图，填写画面要求，然后点击 **开始生成**。
5. 生成图片会显示在页面，并自动保存到本整合包的 `output/` 文件夹。双击 **停止创作台.cmd** 可关闭本包启动的服务。

保存和检查设置只校验本地配置格式，不会发送收费生图请求。点击开始生成后，参考图片和提示词会提交给你配置的服务商，费用与模型能力以该服务商为准。

## 接口设置

- **接口地址**：填写服务商提供的 HTTP 或 HTTPS 地址。可以填写基础地址，也可以填写完整生图接口地址，具体规则见下表。
- **API Key**：填写该地址对应的密钥。已有密钥时，留空保存会保留原密钥；可使用界面的清除操作删除。页面不会回显完整密钥。
- **模型名称**：填写服务商要求的完整模型标识，与服务商后台显示保持一致。
- **协议**：请求格式必须与服务商接口一致；仅填写一个能够访问的地址，并不能使不同协议自动兼容。

本版本支持 Images 图片编辑协议和 Qwen JSON 图片生成／编辑协议。含人物、姿势、服装参考的请求会按最终提示词的图片编号依次提交全部参考图片。服务商模型需要支持多图编辑，并能接受此次选择的参考图数量；如果模型不支持，请更换支持该能力的模型或减少参考，不要只配置文生图模型。

| 协议 | 基础地址示例 | 含参考图片时的完整请求路径 |
| --- | --- | --- |
| Images 图片编辑（multipart） | `https://api.example.com/v1` | `https://api.example.com/v1/images/edits` |
| Qwen JSON | `https://服务商域名/compatible-mode/v1` | `https://服务商域名/compatible-mode/v1/images/generations` |
| LK tt-image-2.5 异步任务 | `https://api.lk888.ai` | `https://api.lk888.ai/v1/media/generate` |

使用 LK 的 `tt-image-2.5` 系列时，可选择 **LK tt-image-2.5 · 异步任务**：提交后立即保存服务商任务号，每隔至少 5 秒查询 `/v1/skills/task-status`，生成完成后下载到 `output/`。查询连接中断会继续查询原任务，重启程序也能恢复，不会自动重复提交收费生图。最多查询两小时，之后可点击“重新查询生成结果”继续取回原任务。已确认失败的服务商任务会显示失败原因，不会自动重新生图。

该协议专用于 LK 的 `tt-image-2.5`、`tt-image-2.5-flare`（标准版）和 `tt-image-2.5-sunburst`（增强版）。默认模型名使用标准版参数；每张参考图最多 10 MB，合计最多 30 MB，以内联图片传递，不需要另外准备公网图片链接。其他服务商继续按其文档选择 Images 或 Qwen JSON，同步请求被中间网络断开时，仍应先核对服务商任务记录。

只填写域名（例如 `https://api.example.com`）时，默认补上 `/v1`，Images 请求将发往 `/v1/images/edits`，Qwen JSON 请求将发往 `/v1/images/generations`。带自定义路径的基础地址会保留原路径；也可直接填写对应的完整请求地址，程序不会重复拼接。若服务商使用根路径 `/images/edits`，请明确填写完整地址。API 设置中会显示本次请求地址，404 时请按服务商文档核对路径与协议。请使用真实域名和区域，表中地址仅展示路径规则。

人物参考最多两张，姿势和服装各一张，合计最多四张。第二张用户图片可以作为另一位人物、同一人物补充或场景参考，作用与原创作台一致。API 模式使用通用的中文自然语言描述，以“参考图1、参考图2”等普通文字说明各图用途，编号对应实际提交顺序，不使用本地 Qwen 的 `<image1>` 标签或 PE 专用结构。最终提示词预览直接展示正文，复制与实际提交使用相同内容；预览不会调用生图 API。

尺寸策略默认使用服务商自动尺寸，画面比例通过提示词表达；如服务商支持传入具体尺寸，可以切换为使用页面所选尺寸。画面尺寸最终由服务商和所选模型决定；API 版不使用本地 ComfyUI 的采样步数、随机种子和 LoRA 设置。

## 本地文件与后续更新

右上角外观按钮支持 **日间、夜间、跟随系统**，选择会在当前浏览器中记住。清晰白底／深黑底与亮蓝重点色覆盖创作台、图库及 API 设置弹窗；切换主题保留当前参考图和任务，图片本身保持原色。可展开区域使用带箭头和“展开／收起”提示的整行标题栏。

- `runtime/node/`：随包的 Node.js 运行环境与许可证。
- `.local/api-settings.json`：首次保存后创建的本机接口设置，包含 API Key。
- `.local/` 中的参考与任务文件：用于提交参考图片、保存任务状态和恢复结果。
- `output/`：生成结果。请自行备份需要保留的图片。

本包只在本机提供页面和设置接口。请将自己的 API Key 保存在个人电脑，不要在分享整合包时附带 `.local/` 或 `output/` 文件夹。重新运行官方打包脚本时会从源文件白名单创建干净的新包，不会复制这些个人文件。更新时保留上述个人目录即可沿用设置与图片。

## 常见情况

- **保存配置后仍无法生成**：检查接口协议、完整接口路径、密钥对应区域、模型名称以及服务商额度。保存配置成功仅表示格式有效。
- **服务商提示不支持图片或图片数量**：选择支持图片编辑和多参考图的模型，确认其最多接受几张图片。
- **服务商不接受所选尺寸**：选择该模型支持的尺寸后重试。
- **生成超时或返回异常**：先在服务商后台核对本次请求，避免反复点击造成重复扣费；具体错误会显示在创作台。
- **本机端口被占用**：从本包启动程序打开页面，程序会自动选择可用端口；请勿把另一个整合包的页面当作当前包使用。
