## 1.2.3 修复与旧版升级

修复旧版停在首次安装页时，更新工具在文件准备完成后收到 409 冲突而中止的问题。旧包请先运行 **停止创作台.cmd**，再运行 **更新创作台.cmd**。如仍失败，下载 GitHub 仓库 ZIP、完整解压后运行其中的 **安装或更新.cmd**，选择原整合包目录，以新版更新工具升级。关闭网页不会停止后台服务；生成、下载或安装任务未结束时仍会阻止更新。

修复部分电脑的本机请求 `Origin` 丢失端口后，安装页脚本和样式返回 403、环境检测停在初始提示的问题。已下载旧版整合包时，先运行 **停止创作台.cmd**，再运行 **更新创作台.cmd**，更新完成后重新启动并按 **Ctrl+F5** 刷新。无需重下环境、模型或完整整合包；夸克包若仍为旧版，也可直接更新。

## 安装位置与换盘

整合包文件夹使用英文名，例如 **AI-Studio-1.2.3**（旧包可能为 `AI-Studio-1.2.1`，更新不强制改名）。可放在任意有写入权限的本地盘，例如 `D:\AI-Studio-1.2.3` 或 `E:\Tools\AI-Studio-1.2.3`，不要求 F 盘，也不需要沿用作者电脑上的目录。建议使用较短的路径，避免放在需要管理员权限的系统目录中。

换盘或改名时，先运行 **停止创作台.cmd**，再移动整个文件夹；之后从新位置双击 **启动创作台.cmd**。内置环境、默认的 `models/`、`output/`、`.local/` 和更新工具都会按新位置工作。保留内部文件与子目录结构。

如果在设置中手动指定了整合包外的模型目录、已有 ComfyUI 目录或 Python 路径，这些是绝对路径；对应目录也搬动后，需要在 **安装与模式** 中重新选择。只移动整合包、外部目录没动时，无需修改。

## 首次启动

1. 保留整合包的完整目录结构，双击 **启动创作台.cmd**。
2. 在安装页选择 **外接生图 API**、**内置 WebUI** 或 **接入已有 ComfyUI**。
3. 填写所选方式的配置，保存后进入创作台。以后启动会记住选择；通过右上角 **安装与模式** 可重新设置。
4. 图片自动保存在 `output/`。使用 **停止创作台.cmd** 关闭本包启动的服务。

不知道选哪种方式时，可按下表选择：

| 使用方式 | 适合情况 | 需要准备 |
| --- | --- | --- |
| 外接生图 API | 已有支持多图编辑的生图接口 | 接口地址、API Key 和模型名称；无需本地模型 |
| 内置 WebUI | 使用整合包附带的环境在本机生图 | Qwen 模型三件套；内置引擎由创作台自动启动 |
| 接入已有 ComfyUI | 已有可用的 ComfyUI 和模型 | 服务地址或安装目录，沿用已有模型与节点 |

## 日常生成

1. 按需上传人物参考图，在下方图库选择姿势和服装。第二张人物参考可用于第二位人物、同一人物补充或场景。
2. 填写画面要求；没有人物参考时，补充需要生成的人物描述。
3. 点击 **开始生成**，等待队列和进度完成。生成期间保持创作台服务运行。
4. 在结果区下载图片，或到根目录的 `output/` 查看自动保存的文件。更换使用方式时，打开 **安装与模式**。

## 外接生图 API

填写接口地址、API Key、模型名称，选择 Images multipart 或 Qwen JSON 协议。模型需要支持图片编辑及本次使用的参考图数量。人物参考最多两张，姿势和服装各一张，共最多四张。

只填域名时默认补上 `/v1/images/edits`（Images）或 `/v1/images/generations`（Qwen JSON）。自定义基础地址保留已有路径，也可填写完整接口路径；API 设置中会显示请求地址。保存配置和提示词预览不会调用收费生图请求。实际生成时，图片与提示词会提交给所配置的服务商。

API 模式的提示词使用通用中文自然语言描述，以“参考图1、参考图2”等普通文字对应人物、姿势、服装和场景的实际上传顺序，不使用本地 Qwen 的图片标签和 PE 结构。预览直接显示描述正文，可复制使用；本地 ComfyUI 模式继续使用原有提示词格式。

已有 API Key 时留空保存会继续沿用。密钥仅保存在 `.local/api-settings.json`，不会在页面回显。创作台中的“生图 API 设置”可修改协议、尺寸传递策略及密钥。

使用 LK 的 `tt-image-2.5` 系列时，可选择 **LK tt-image-2.5 · 异步任务**。程序保存服务商任务号后查询原任务，断线或重启后继续取回结果，不会自动重复提交收费生图。每张参考图最多 10 MB，合计最多 30 MB。默认标准版，增强版模型名填写 `tt-image-2.5-sunburst`。具体协议和恢复说明见 `docs/API版使用说明.md`。

## 内置 WebUI

内置方式使用整合包中附带的 ComfyUI 和 Python，**无需额外下载环境**。只需自动下载 Qwen 模型，或手动放好模型后检测。当前环境为 Windows x64 / NVIDIA / CUDA 13，显卡驱动由系统提供。

本地准备面板显示 **内置运行环境** 和 **下载 Qwen 模型**。环境会自动检测为就绪；如果环境文件缺失，请重新下载完整整合包，保留自己的 `models`、`output` 和 `.local` 目录。需要安装系统 VC++ 运行库时，使用随包的 **修复运行库.cmd**。

模型 **自动下载** 会自动放到指定目录并校验，默认使用 **国内镜像 · HF-Mirror**。在“文件位置与下载选项”中可切换到 **Hugging Face 官方**，官方源在部分国内网络可能需要代理。两种来源使用相同版本的权重和官方 SHA-256；取消、重启或切换来源后可继续下载，网络故障最多自动尝试三次。

模型 **手动下载** 使用 **[Qwen 模型三件套 · 夸克网盘](https://pan.quark.cn/s/80d2ba176a41)**。把其中的 `models` 文件夹与“启动创作台.cmd”放在同一级，然后点击 **检测模型**；无需逐个导入，也不会复制或移动模型。检测会检查三个文件的大小与 SHA-256，明确显示缺失或不匹配的文件。保留 `diffusion_models/qwen2.1`、`text_encoders/qwen2.1`、`vae/qwen2.1` 层级，精确路径见展开的文件清单。三件套为 INT8 主模型、FP8 文本编码器、BF16 VAE。

正确的模型位置如下。不要放成 `models/models/`，也不要改动模型文件名：

```text
AI-Studio-1.2.3/
├── 启动创作台.cmd
├── 更新创作台.cmd
├── runtime/
└── models/
    ├── diffusion_models/qwen2.1/qwen_image_2.1_int8_convrot.safetensors
    ├── text_encoders/qwen2.1/qwen3vl_8b_fp8_scaled.safetensors
    └── vae/qwen2.1/qwen_image_2.1_vae_bf16.safetensors
```

已有其他模型目录时，展开“连接设置与已有模型目录”，保存对应的 `models` 根目录后检测即可；校验记录保存在本项目内，不会改动已有权重文件。环境和模型均检测就绪后，可启动本地生图。

完整整合包放在夸克，GitHub 只提供项目介绍与小型程序更新。整合包和更新仓库地址由 `config/distribution.json` 管理，模型下载地址由 `config/model-catalog.json` 管理。

## 接入已有 ComfyUI

- **连接服务地址**：填写本机或局域网已运行的 ComfyUI 地址，例如 `http://127.0.0.1:8188`。创作台使用它的模型与节点。
- **从安装目录启动**：填写已有整合包目录或含 `main.py` 的 ComfyUI 目录，点击 **识别环境**。程序会尝试识别 `python_embeded`、`python_embedded`、`python` 或 venv 中对应的 Python，也可手动指定 Python 可执行文件。

目录启动会优先复用所配置地址上已运行的服务；否则使用选定 Python 启动一个由本程序管理的 ComfyUI 进程。启动与停止只作用于本程序创建的进程。该环境仍需具备 Qwen-Image 2.1 标准版模型和对应节点。

## 本机设置与切换

右上角的外观按钮可选择 **日间、夜间、跟随系统**。界面使用清晰白底／深黑底与亮蓝重点色，图库、设置窗口和安装页共用主题；选择保存在当前浏览器，切换外观不会清空参考图或生成任务。图片与优优保持原色。姿势描述、最终提示词、生成设置和手动导入等可展开区域均有整行标题栏、箭头与“展开／收起”提示，可用键盘操作。

安装方式记录在 `.local/studio-settings.json`，本地环境配置记录在 `.local/local-settings.json`。API 和 ComfyUI 的任务状态分别记录，已有结果保存在 `output/`。生成或下载期间需先完成或取消任务，再切换方式或停止服务。

## 后续更新

GitHub 的更新目录只包含项目介绍和 **更新文件**，不包含运行环境、模型及完整图库。它不能作为首次安装使用。

整合包内的 **更新创作台.cmd** 已绑定 [GitHub 更新仓库](https://github.com/chengjing84/annoyoo-studio-updates)。双击后会检查 main 分支的新版本；确认更新后，自动下载与校验文件、备份被替换的程序文件、平滑关闭空闲服务、应用更新并重启。

已经下载的旧版整合包需要先补入一次更新工具：从仓库下载并解压更新，双击 **安装或更新.cmd**，选择原整合包根目录。此方式直接使用下载目录内的离线文件，无需再连接 GitHub。完成后，原目录中会出现 **更新创作台.cmd**。

生成或下载任务进行中时不会应用更新。文件先逐一核对 SHA-256，再修改程序；备份保存在 `.local/update-backup-*`。替换或重启失败时恢复原程序。GitHub 无法连接时仍可使用 **安装或更新.cmd** 安装离线更新。请在更新完成前保持更新窗口打开。

更新文件不涉及 `runtime/`、`models/`、`output/`、`.local/` 和完整图库，个人设置、密钥、模型和图片会保留。版本与运行环境兼容要求见更新目录的 `update-manifest.json`；环境或图库资源升级另发完整整合包。

维护者修改 `config/distribution.json` 中的版本后，运行 `python -B scripts/build-integrated-release.py`，会生成未压缩的完整整合包和 GitHub 更新目录。工具使用白名单并逐文件校验，排除个人设置、任务、模型和生成图片。
