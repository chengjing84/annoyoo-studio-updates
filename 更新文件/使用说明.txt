杏野创作台 1.2.0 · 完整整合包（不含模型）

本包包含主程序、完整姿势与服装图库、Node.js、Python、PyTorch、ComfyUI 和 VC++ 运行库安装器。
保持全部目录层级，双击“启动创作台.cmd”。无需另下环境。
首次选择外接 API、内置 WebUI 或已有 ComfyUI。API 模式无需本地模型。
内置生图：自动下载 Qwen 模型，或从夸克手动下载并将 models 放到本目录，再点击检测模型。
Windows x64 / NVIDIA；显卡驱动需支持 CUDA 13。

更新：先停止创作台，把 GitHub 下载目录中“更新文件”里面的内容复制到此目录，选择替换。
更新前可备份整合包；更新文件不包含 runtime、models、output 和 .local。
版本与兼容要求见 GitHub 的 update-manifest.json。环境升级另发新的完整整合包。
设置与密钥在 .local，图片在 output，模型在 models，请妥善保留。
